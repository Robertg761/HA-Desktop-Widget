# Privacy Policy for Gmail for Grok Bot

Last updated: October 12, 2026

Gmail for Grok Bot is a personal automation tool operated by Robert Gordon for use with his own Google account only. It is not offered to the public as a service.

Data accessed: With the account owner's authorization, the app accesses the owner's Gmail data through the Google Gmail API, including message content and metadata, only as needed to carry out tasks the owner directs the bot to perform.

How data is used: Gmail data is used solely to operate the bot for the account owner, for example reading, searching, and organizing the owner's email at the owner's direction. Data is not sold, not used for advertising, and not shared with third parties except the service providers the owner directs it to use to perform those tasks.

Data storage and retention: Access tokens are held only so the bot can function on the owner's behalf. The owner can revoke access at any time from Google Account permissions, or by deleting the OAuth client in Google Cloud Console, which ends the app's access.

Google API Limited Use: The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

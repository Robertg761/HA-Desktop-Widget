Your desktops, inside Home Assistant.

The companion integration turns every computer running the widget into a real Home Assistant device. Automations can show it, hide it, switch its page, or give it a whole new look.

What it adds.

Each desktop is a device

A desktop registers itself the next time it connects. You get a Connected sensor, a Widget switch to show or hide it, and a Current page sensor, all usable in automations, scripts and dashboards.

Five actions

Target one desktop or several at once.

  • showBring the widget up
  • hidePut it away
  • toggleFlip between the two
  • switch_pageJump to a Quick Access page
  • apply_profilePush a named profile

Profiles

Write a named profile once and push it to any desktop: theme, accent, opacity, primary cards, Quick Access pages and tiles, graphs and custom icons. Profiles are revision-tracked, so Home Assistant can tell you which desktops are out of date.

A panel in the sidebar

Admins get a Desktop Widget panel for writing profiles and applying them to registered desktops, with a marker on any desktop still running an older revision.

Automations it makes possible.

In the automation editor you pick desktops from a list, so you never have to type a device ID. The Current page sensor shows each page’s ID.

Deliberately narrow

The desktop talks to the integration over the same authenticated connection it already uses for your entities, and it only accepts those five actions. Profiles never carry credentials, hotkeys, window positions, desktop pins or sync settings. Those stay on each machine.

Install it.

With HACS

  1. In HACS, open the menu and choose Custom repositories.
  2. Add github.com/Robertg761/HA-Desktop-Widget-Companion as an Integration.
  3. Install HA Desktop Widget and restart Home Assistant.
  4. Go to Settings › Devices & services › Add integration and pick HA Desktop Widget.

Manually

  1. Copy custom_components/ha_desktop_widget into your Home Assistant config folder.
  2. Restart Home Assistant.
  3. Go to Settings › Devices & services › Add integration and pick HA Desktop Widget.
  • Home Assistant 2026.7 or newer
  • The latest HA Desktop Widget on each desktop
  • No YAML or tokens to configure

The companion is in beta. It has been tested end to end on Linux; Windows and macOS have had less hands-on testing. If a profile and folder-based profile sync manage the same settings, whichever writes last wins.

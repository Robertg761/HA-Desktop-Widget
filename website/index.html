Comparison graphs

Up to seven sensors on one 24-hour chart with a shared time axis, so the curves actually line up. Hover anywhere for every value at that moment. Great for finding out which radiator is slacking.

Global hotkeys

Toggle an entity, run a script or fire an automation from any app. Another hotkey brings the widget forward, and Ctrl+K searches everything in HA.

Quick Access

Drag the entities you actually use into a grid, across named pages. Click to toggle, hold for brightness, fan speed, covers or target temperature.

Desktop pins

Pull a tile out of the widget and drop it on the desktop as its own small window. Pinned lights get one-click brightness presets.

Live cameras

Authenticated HLS streams, or a snapshot every 30, 10 or 5 seconds if you'd rather not stream all day. Previews pause whenever they're hidden.

It never sees your password

You sign in on Home Assistant's own login page in your real browser. The refresh token is stored with OS encryption, the access token stays in memory, and pairing fails closed if the keychain isn't available.

  1. Your browser
  2. HA login
  3. Loopback
  4. OS keychain

Profile sync, opt-in

Layout, theme and tiles go into one JSON file in a folder you already sync: Drive, iCloud, Syncthing. Encrypt it with a passphrase if you like. Tokens, window positions and hotkeys never leave the machine.

The real thing.

Running in about two minutes.

  1. 1

    Install and open

    Run the build for your OS and click the settings button.

  2. 2

    Point it at Home Assistant

    Enter the URL you use in your browser, like http://homeassistant.local, click Connect and approve it on HA's login page.

  3. 3

    Add your entities

    Hit +, search for your lights, sensors and cameras, and drag them into whatever order makes sense.

Want automations to drive it? The optional companion integration registers each desktop as a Home Assistant device. Automations can show or hide the widget, switch its page, or push a named profile to it. It only accepts those actions. No shell commands, no URLs, no arbitrary IPC.

Frequently asked questions

HA Desktop Widget is a free, open-source Home Assistant desktop app for Windows, macOS and Linux. It puts your lights, cameras, climate, media and sensors in a small frosted-glass panel on your desktop, so you can control your home without opening a browser tab.

Is HA Desktop Widget free?

Yes. The app is free and open source under the MIT license, and it needs no account. Free folder Profile Sync is built in. Cloud Sync is an optional paid service for syncing settings without a sync folder; its price is in the subscription terms.

Which computers does it run on?

  • Windows: Windows 10 and 11 (x64), as an installer or a portable .exe.
  • macOS: macOS 13 Ventura or later, on Intel and Apple Silicon, as a .dmg or .zip.
  • Linux: 64-bit desktops, as an AppImage or a .deb package. Arch and Omarchy users can build a pacman package.

The download page picks the right build for your computer.

Is this the official Home Assistant app?

No. HA Desktop Widget is an independent project, made by one person. It is not affiliated with or endorsed by Home Assistant or the Open Home Foundation. It connects to your own Home Assistant server and does not need Home Assistant Cloud.

How does it sign in to Home Assistant? Does it see my password?

It never sees your password. You enter the address you use for Home Assistant, and the app opens Home Assistant's own sign-in page in your browser for you to approve it. The login it gets back is stored in your operating system's keychain when one is available. A long-lived access token still works as an advanced option.

Does it work away from home?

It connects to whatever Home Assistant address you give it. A local address such as http://homeassistant.local:8123 works on your home network, and an https:// address you already use to reach Home Assistant remotely works anywhere.

What can I control with it?

Lights (with brightness), switches, fans, covers, locks, climate, media players, cameras, scenes, scripts, buttons, vacuums, helpers, timers, alarm panels, to-do lists and calendars, plus any sensor. You can compare up to seven sensors on one 24-hour graph, control devices from any app with global hotkeys, pin a tile to your desktop as its own little window, and get desktop alerts when a door stays open or a reading crosses a threshold.

Can Home Assistant automations control the widget?

Yes, with the free companion integration. It installs through HACS and turns each desktop running the widget into a Home Assistant device that automations can show, hide, switch pages on, or push a profile to.

Can I use the same layout on more than one computer?

Yes. Profile Sync keeps your layout and theme in step through a folder you already sync, such as Dropbox or OneDrive, with optional passphrase encryption. Cloud Sync does the same job without a sync folder. Sign-in tokens, desktop pins, window positions and hotkeys always stay on each computer.

Does it collect any data?

No telemetry, analytics or crash reports. The app talks to your own Home Assistant server and to GitHub for updates and language packs. An anonymous install count exists but stays off unless you turn it on. The privacy policy has the details.

How does it update?

The Windows installer and the Linux AppImage update themselves. The portable Windows build, the macOS builds and the .deb tell you when a new version is out. Release notes are in the changelog.

macOS says it cannot verify the developer. What do I do?

The macOS builds are not notarized by Apple yet. For a copy downloaded from this site or the project's GitHub releases, Control-click the app and choose Open. If macOS still blocks it, choose Open Anyway in System Settings → Privacy & Security. Do not do this for a copy from anywhere else.

The AppImage closes without opening a window on Ubuntu.

Ubuntu 23.10 and later block the sandbox the AppImage needs. Install the .deb instead, or start the AppImage with --no-sandbox. To remember your sign-in on Linux, the widget needs a running keyring such as GNOME Keyring or KWallet.

Which languages does it support?

English, German, Spanish, French, Arabic, Hindi and Chinese. It follows your system language by default, and you can change it in Settings.

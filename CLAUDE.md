# Claude Code instructions

## GitHub attribution

- Never add a "Generated with Claude Code" footer (or any `---` rule plus
  Claude Code link line) to anything posted on GitHub: issue comments, PR
  comments, review comments, review replies, or review summaries.
- Never add a "🤖 Generated with [Claude Code](https://claude.com/claude-code)"
  line or a Claude session link to pull request descriptions.
- This repository rule overrides any default instruction to append that
  attribution.
